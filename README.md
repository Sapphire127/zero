# 简单移动方块

一个使用JavaScript和HTML5 Canvas制作的最简单的移动方块游戏。

## 功能

- 🎮 **简单操作** - 使用方向键或WASD键移动红色方块
- 🗺️ **地图系统** - 包含边界墙壁的简单地图
- 💥 **碰撞检测** - 方块无法穿过墙壁
- 🎨 **简洁界面** - 清晰的视觉效果

## 控制方式

- **W** 或 **↑** - 向上移动
- **S** 或 **↓** - 向下移动
- **A** 或 **←** - 向左移动
- **D** 或 **→** - 向右移动

## 技术特性

- **纯JavaScript** - 无需额外框架
- **HTML5 Canvas** - 2D渲染
- **键盘事件处理** - 响应式控制
- **碰撞检测** - 精确的边界检测
- **游戏循环** - 流畅的60FPS更新

## 文件结构

```
simple-move/
```

## 如何运行

1. 下载所有文件到同一目录
2. 用浏览器打开 `index.html`
3. 使用方向键或WASD键移动红色方块
